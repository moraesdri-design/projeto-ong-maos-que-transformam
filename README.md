# projeto-ong-maos-que-transformam

Projeto acadêmico de Front End Web - ONG Mãos que Transformam

## Tecnologias utilizadas

O projeto utiliza HTML5 para a estrutura das páginas, CSS3 para os estilos e JavaScript para as funcionalidades. Também são utilizados módulos ES6 e Local Storage para organização do código e armazenamento dos dados do formulário.

## Estrutura do projeto

O projeto está organizado em páginas HTML, folha de estilos CSS, pasta de imagens e módulos JavaScript. Os módulos JavaScript são responsáveis pela inicialização da aplicação, navegação, formulário e armazenamento dos dados.

## Estratégia de Versionamento

O projeto utiliza uma estrutura baseada no GitFlow, com as branches main, develop e feature/atividade-4.

- main: versão estável do projeto.
- develop: ambiente de desenvolvimento.
- feature/atividade-4: desenvolvimento das funcionalidades desta atividade.
